# Модели

Файлы здесь в git не коммитятся (`*.pt`, `*.onnx`, `*.fbx` в `.gitignore`). Положите их вручную.

| Файл | Что это | Где используется |
|---|---|---|
| `best.pt` | YOLO26s-seg, один класс `truck`, imgsz 960, дообучена на кадрах видео проекта | шаг `detect` (`--weights`) |
| `CargoTruck.fbx` | 3D-модель грузовика из сцены Unreal (жёсткий грузовик, 6.69 × 1.68 × 2.42 м в файле) | трекер реального времени (`--truck-fbx`) |

Замечания:
- ultralytics принимает только расширение `.pt`: файл вида `best.pt-2` переименуйте.
- YOLO дообучена на этих же видео, поэтому проверка на них — оценка на обучающих данных.
- Без `CargoTruck.fbx` трекер работает с коробкой 16.5 × 2.55 × 4.0 м (заметно хуже).
- В сцене актор грузовика масштабирован ×3.186 (`--truck-scale`), см. `reconstruction/truck_model.py`.

Проверка после замены весов или модели:
```
.venv/bin/python main.py --weights models/best.pt --redetect --video
```
