# Демонстрация потокового конвейера на синтетических видео

Реальных видео в среде разработки не было, поэтому пять видеофайлов камер отрендерены по той же
синтетической сцене, что и детекции (`tools/render_synthetic_video.py`: коробка грузовика, сетка
дороги, позы камер и траектория из `tools/make_synthetic_data.py`). Детекции — готовые (без YOLO).

Команда (режим `replay`, готовые детекции вместо YOLO, видео с наложением):

```bash
python tools/render_synthetic_video.py --data tmp/synthetic
python stream.py replay --data tmp/synthetic --detections outputs/synthetic/detections --out outputs/synthetic/demo --video --no-pacing
```

Результат: `outputs/synthetic/demo/videos/stream_cam{1..5}.mp4` (1001 кадр, 30 FPS): синяя рамка —
модель по фильтру, жёлтый крест и след — центр кабины (REALTIME TRACK), зелёный круг и след —
SMOOTHED TRACK (сплайн, задержка 5 кадров), серая рамка — детектор, красный ромб — CSV цели (только
оценка), HUD — координаты, СКО, скорость, ускорение, курс, статус, камеры, тиков/с, задержка.
Кадры из видео: `frame_cam*_f*.png`; графики прогона: `01..04_*.png`.

Два измерения производительности (4 ядра CPU, без GPU, детекция — чтение готовых детекций):

| прогон | тиков | тиков/с | задержка p50 / p95, мс | пропущено кадров | отчёт |
|---|---|---|---|---|---|
| в исходном темпе 30 FPS (`--video`, кадры вытесняются, если не успеваем) | 348 из 1001 | 10.3 | 18.9 / 50.4 | 37.7 % | `performance_report_realtime_paced.md` |
| без потерь (`--no-pacing`, каждый кадр) | 1001 | 10.4 | 278 / 336 (ожидание в очереди) | 0 | `performance_report_lossless.md` |

Узкое место обоих прогонов — визуализация пяти камер 1080p (87 мс на тик, этап `visualization`),
сам конвейер без неё — 7 мс на тик. Для демонстрации в реальном темпе следует рисовать одну-две
камеры (`output.video_cameras`) или выносить запись видео в отдельный процесс.
